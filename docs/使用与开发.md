# 专注 · Focus

Focus 是使用 C++20、GTK4 和 libadwaita 编写的 Linux 桌面应用，通过 GTK 与 libadwaita 的 C 接口构建原生界面。应用提供番茄钟、长期任务、速记和统计四个页面，界面跟随系统的语言、浅色、深色和强调色设置。

## 构建与运行

构建需要 C++20 编译器、CMake 3.24 或更新版本、pkg-config、GNU gettext 工具，以及 GLib、GTK 4.16 或更新版本、libadwaita 1.6 或更新版本、SQLite3、cmark-gfm、libdbusmenu-glib 和 libcanberra 开发文件。Ninja 可作为构建工具。依赖通过 pkg-config 检测，Markdown 使用 [cmark-gfm](https://github.com/github/cmark-gfm) 解析。系统提示音需要安装 XDG 声音主题，例如 `sound-theme-freedesktop`。

在项目根目录执行：

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/focus
```

运行需要可用的 Wayland 或 X11 桌面会话。安装到用户目录后，可从桌面应用菜单启动：

```bash
cmake --install build --prefix "$HOME/.local"
```

可执行文件安装在 `~/.local/bin/focus`，该目录需要位于 `PATH` 中。桌面入口和图标安装到用户的 `share` 目录。

关闭窗口时，应用保存普通窗口的尺寸和最大化状态。下次启动会恢复这些设置；在最大化状态下关闭时，保存的尺寸仍为最大化前的普通窗口尺寸，再次启动后退出最大化即可恢复该尺寸。窗口尺寸受桌面可用空间和应用最小尺寸限制。

## Arch Linux 软件包

`packaging/arch/` 包含 Arch Linux 的 `focus-git` 包，从 GitHub 仓库的默认分支构建当前代码。系统安装 `base-devel` 与 `git` 后，在该目录执行 `makepkg -si` 即可构建并安装，`-s` 会从仓库补齐 GTK4、libadwaita、SQLite 和 cmark-gfm 等依赖。

`pkgver()` 读取 `CMakeLists.txt` 中的项目版本，拼接提交数量与短提交哈希，得到形如 `0.1.0.r3.g97626e6` 的版本号，每次构建按当时的 HEAD 重新计算。包内包含 `focus` 可执行文件、桌面入口、图标和 MIT 许可证文件。`focus-git` 通过 `provides` 与 `conflicts` 声明它与名为 `focus` 的包互斥。构建启用 `BUILD_TESTING`，`check()` 阶段运行 `core_test` 测试。

## 语言

应用使用 gettext，支持英文和简体中文；其他语言回退到英文。中文导航中的速记在英文界面中显示为 Quick Notes。语言在启动时读取，任务名称和笔记内容保持用户原文。新建笔记的默认标题使用创建时的界面语言。

可以通过环境变量指定语言。先从应用菜单退出正在运行的实例，再运行以下命令之一；已有实例会保留启动时的语言。

```bash
LANGUAGE=en LC_ALL=en_US.UTF-8 ./build/focus
LANGUAGE=zh_CN LC_ALL=zh_CN.UTF-8 ./build/focus
```

上述示例要求系统已生成对应的 UTF-8 locale。`src/i18n.hpp` 提供 `_()` 文本翻译、`P_()` 单复数翻译和 `i18n::format()` 格式化接口。动态文本使用完整的格式字符串，数值和用户内容通过参数传入。中文翻译保存在 `po/zh_CN.po`，构建时校验格式并生成 `focus.mo`，安装到 `share/locale/zh_CN/LC_MESSAGES/`；构建目录也可直接加载翻译。

修改界面文本后，可生成翻译模板并更新目录：

```bash
cmake --build build --target update-pot
msgmerge --update --backup=none po/zh_CN.po build/focus.pot
cmake --build build
```

## 计时与任务

番茄钟默认包含 25 分钟专注、5 分钟短休息、15 分钟长休息，每完成 4 个番茄进入长休息。点击窗口右上角的设置按钮可修改这些周期。设置范围为专注 1–180 分钟、短休息 1–60 分钟、长休息 1–120 分钟、长休息间隔 2–12 个番茄。保存设置会重置当前循环中的番茄数量。

在长期任务页面创建任务后，可在番茄钟页面的任务选择器中选择该任务并启动番茄钟或正向计时。自由专注用于无需关联任务的计时。长期任务页面提供改名、完成和重新打开操作，完成任务后仍保留历史统计。

暂停会保留本轮进度，继续计时会从该进度恢复。结束并保存会将已经发生的专注时长计入统计，并将计时器重置为专注阶段。每个番茄或休息阶段结束后，应用会提示并等待手动启动下一阶段。完成的番茄数量仅包含完整结束的专注倒计时。

重置按钮提供两个选项。重置当前计时会清除当前专注或正向计时的已记录时长，将当前阶段恢复到初始时长，并保留本周期已经完成的番茄钟；在休息阶段重置时，保留休息阶段并恢复完整休息时长。重置整个番茄钟周期会删除本周期全部专注记录，包括已经完成和手动结束并保存的记录，并归零轮次、返回第一轮专注。两种重置都会停止计时并等待手动开始，同时更新任务时长、每日统计和完成数量。正向计时仅支持重置当前计时。

一个番茄钟周期由设置的专注轮次和对应休息组成，以长休息结束为边界。完成或结束长休息后开始新周期，已结束周期的记录会保留。切换计时模式、保存周期设置或退出应用也会保留现有记录，并在下一次计时中开始新周期。

正在计时或暂停后仍有进度时，结束当前计时即可切换任务、模式和周期设置。切换页面、最小化或关闭窗口都会保持计时。每个阶段完成时会发送桌面通知，点击通知可显示窗口。专注或休息自然结束时，还会通过 libcanberra 播放当前系统声音主题中的 `alarm-clock-elapsed` 提示音，遵循 GTK 的系统音效开关及系统音量。暂停、重置和提前结束计时不会播放结束音效。音效不可用时，计时记录和桌面通知继续工作。

## 后台运行

关闭窗口或按 `Ctrl+W` 会保存笔记和窗口状态，将窗口隐藏，计时继续在后台运行。再次从应用菜单或命令行启动 Focus 会唤回原窗口，同一桌面会话内只运行一个实例。在窗口右上角的应用菜单或托盘菜单中选择退出，或按 `Ctrl+Q`，会保存记录并结束进程；结束进程后重新启动会开始新的专注阶段。

系统托盘提供显示窗口、开始或暂停计时、退出操作，并显示当前计时状态。托盘菜单通过 libdbusmenu-glib 导出，桌面需要支持 StatusNotifierItem。桌面未提供托盘服务时，可以重新启动 Focus 来显示原窗口，再使用应用菜单退出。GNOME 用户可以使用支持 AppIndicator/StatusNotifierItem 的扩展。

计时运行期间，应用通过 GTK 请求系统抑制休眠，暂停、阶段结束或退出时释放请求。是否允许抑制由桌面会话决定，用户仍可强制挂起系统。计时使用包含挂起时间的 Linux `CLOCK_BOOTTIME`；唤醒后，正向计时累计实际经过的时间，番茄钟最多累计到本阶段结束。延迟收到的完成事件按实际结束时间计入对应日期，下一阶段仍等待手动启动。

## 笔记

速记按最近修改时间展示笔记，可按标题和正文搜索。新建笔记后可编辑标题和 Markdown 源码，停止输入约 600 毫秒后自动保存。切换笔记、切换页面和关闭窗口前也会保存。编辑器支持撤销与重做，预览页展示渲染后的内容。

预览支持标题、段落、粗体、斜体、删除线、列表、任务列表、引用、代码和表格。链接显示文字及地址，图片显示替代文字及地址。原始 HTML 以文本显示，预览不执行 HTML，也不请求网络图片。笔记保存在本地 SQLite 数据库中，不会自动生成独立的 `.md` 文件。删除笔记前会要求确认，删除后无法恢复。

## 统计与存储

统计页展示今日、近七天、累计专注时长、完整番茄数量、每日柱状图和任务累计分布。番茄钟与正向计时共用专注记录，休息和暂停时间不计入统计。跨午夜的记录按记录发生时的系统本地日期拆分。运行中的计时每秒写入一次记录。统计页和任务页只在当前可见、且窗口未隐藏或最小化时每十秒刷新；切回页面或恢复窗口时立即更新。计时结束、删除和重置会立即更新当前可见页面。异常退出时，最近一次写入后的不足一个写入周期可能丢失。

点击近七天柱状图中的日期或柱体，可查看当天的专注记录。记录按开始时间倒序排列，显示任务、计时模式、状态、专注时长，以及按当前系统时区显示的开始和结束时间。专注时长不包含暂停，起止时间之间可以包含暂停。跨天记录会列在各个有专注时长的日期下，同时显示整条记录的时长和当天的时长。旧版保存的记录保留原有时长，未保存的起止时间显示为未记录。

点击记录右侧的删除按钮并确认后，整条记录会永久移除，相关日期、任务累计时长和完成番茄数量会同步更新。删除跨天记录会移除其在所有日期的时长。删除仍在计时或暂停中的记录也会重置当前计时，保留本周期的其他记录。删除历史记录不会改变当前番茄钟的阶段和轮次。

数据默认保存到 `~/.local/share/focus/focus.db`。设置 `XDG_DATA_HOME` 时，保存位置为 `$XDG_DATA_HOME/focus/focus.db`。数据库包含任务、Markdown 原文、专注记录、周期设置和窗口状态。备份或迁移时先关闭应用，再复制整个 `focus` 数据目录；运行时 SQLite 可能使用附属的 WAL 文件。

专注明细长期保留，近七天仅限制图表的显示范围。累计时长、完成数量和任务时长首次读取后缓存在内存中，记录保存与删除成功提交后按差额更新。每日统计按日期索引查询，任务汇总使用覆盖任务、时长和完成状态的索引。统计结果随记录或任务变化失效，本地日期变化时重新计算近七天范围；其他数据库连接提交改动时会清除缓存并重新读取。缓存不写入额外的汇总表，重新启动后从原始记录重建。

## 模块

| 模块 | 职责 |
| --- | --- |
| `src/timer.*` | 独立的计时状态机，使用包含挂起时间的单调时钟计算时长 |
| `src/focus_timer.*` | 专注记录与计时状态协调、周期边界、重置时回退统计 |
| `src/store.*` | SQLite 读写、事务、按本地日期分配专注时长 |
| `src/application.*` | 应用生命周期、计时记录与页面协调、设置 |
| `src/focus_page.*` | 番茄钟、正向计时和当前任务选择 |
| `src/tasks_page.*` | 长期任务管理与累计时长 |
| `src/notes_page.*` | 笔记条目、编辑、搜索与自动保存 |
| `src/markdown.*` | cmark-gfm 语法树到 GTK 文本标签的渲染 |
| `src/stats_page.*` | 专注统计、可点击图表、每日记录明细与删除 |
| `src/tray.*` | StatusNotifierItem 托盘接口、状态显示与菜单导出 |
| `src/event_sound.*` | 系统主题提示音播放与音效开关处理 |
| `src/ui.*` | 共用控件与 C 回调边界的异常处理 |
| `src/i18n.*`、`po/` | gettext 初始化、格式化接口及翻译目录 |
| `data/` | 编译进应用的样式、图标及桌面入口 |

计时与存储层不依赖 GTK。界面通过 C API 调用 GTK4 和 libadwaita，控件使用 GTK 的对象生命周期管理。SQLite 通过预编译语句访问。每次记录以绝对累计时长更新，重复保存同一记录不会重复计时。

## 验证

```bash
cmake -S . -B build -G Ninja -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

核心行为测试覆盖暂停与恢复、倒计时边界、长休息周期、正向计时、亚秒精度、跨午夜和夏令时日期分配、重复保存、任务完成、两种重置的统计回退及数据库重新打开后的数据恢复。测试使用临时数据库，不访问个人数据。

记录测试覆盖起止时间、暂停和跨天明细、删除后的统计一致性、当前记录删除后停止计时，以及旧数据库升级后的数据保留。统计缓存测试覆盖重复保存、任务改名、批量删除、事务失败后的重试、其他连接的修改和本地日期切换。

语言测试覆盖英文、简体中文、未支持语言的英文回退、单复数、自由专注标签和新建笔记标题，并检查用户文本保持原样。启用测试时，构建使用 `localedef`、`en_US` locale 定义和 UTF-8 字符映射在构建目录生成私有 locale，测试通过 `LOCPATH` 使用它，不改动系统 locale。

在可用的桌面与会话总线环境中，可使用 `-DFOCUS_DESKTOP_TESTS=ON` 启用桌面集成测试。后台生命周期测试会创建临时窗口，验证关闭后继续计时、重新激活原窗口、隐藏时暂停和恢复、显式退出及窗口状态保存；没有可用显示服务时会跳过。托盘测试验证图标点击与菜单操作传递窗口激活令牌，并确保令牌只使用一次；没有可用会话总线时会跳过。
